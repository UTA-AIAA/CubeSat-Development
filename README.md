# CubeSat-Development
The goal of the CubeSat Development team is to develop space ready CubeSats in-house. 

This repository contains the design programs for the CubeSat. 

The attached wiki serves as documentation for the projects.

Onshape is a free source that houses the 3D and Parametric models.

The google drive also contains other files.
